# Source notes

Primary narrative spine:

- *Srimad Bhagavata Purana*, Canto 8, chapters 6–9: truce, churning,
  Halahala, Lakshmi, Dhanvantari, and Mohini.
- *Mahabharata*, Adi Parva, Astika Parva, sections 17–19: Mandara, Vasuki,
  amrita, treasures, and the devasuras' conflict.

Reference links consulted:

- https://bhagavata.org/canto8/c8-contents.html
- https://en.wikisource.org/wiki/Page:The_Mahabharata_of_Krishna-Dwaipayana_Vyasa_(Volume_1).pdf/79
- https://www.gutenberg.org/cache/epub/7864/pg7864.html

The sources differ in ordering, emphasis, and some details. This adaptation
uses the Bhagavata sequence for narrative continuity and avoids presenting a
single exhaustive “fourteen treasures” list as universally fixed.
